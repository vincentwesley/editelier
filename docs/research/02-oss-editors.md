# 02 — Open-source editors and reusable crates

Researched 2026-11-25. Licences were read from each repo's `LICENSE` file (GitHub licence API plus file header) or from the crate's crates.io metadata. Star counts and dates are as of the research day. "Reusable" means we may copy or depend on code with attribution; "study-only" means read for ideas, describe in our own words, never copy code, shaders, assets or text.

Editelier target for context: Tauri 2 shell (WebView2 = Chromium on Windows), Rust core, TS UI, wgpu compositor, Media Foundation + LGPL FFmpeg.

## Recommendations

### Reuse (with attribution in `THIRD_PARTY_NOTICES.md`)
- **OpenCut classic `rust/crates`** (MIT): evaluate `gpu`/`compositor`/`effects`/`masks`/`time` as the seed of our wgpu compositor, and keep its `#[export]` native/WASM dual-target trick so the core also runs in the WebView for previews. Pin a commit.
- **OpenReel** (MIT): copy selectively, after a per-file provenance check: LUT `.cube` parser, WGSL effect shaders, easing/keyframe model, caption animation timing, interchange writers. Don't pull in its `@ffmpeg/core` dependency.
- **MediaBunny** (MPL-2.0): use unmodified from npm in the UI for probing, thumbnails and scrub frames via WebView2 WebCodecs. Any patch goes upstream or into a published fork.
- **Crates:** num-rational, ebur128, cosmic-text + glyphon, cpal, rubato, rustfft, nnnoiseless/earshot, image + fast_image_resize, kamadak-exif + little_exif, whisper-rs, ort, rsmpeg or ffmpeg-sidecar (LGPL FFmpeg build), windows-rs.

### Learn (ideas only, in our own words)
- LosslessCut: native-play first, FFmpeg-transcoded preview second, export from the original; keyframe-jump nav; segment list with tags; scene/silence split; a visible "keyframe vs exact cut" choice with an honest warning.
- Kdenlive: per-project proxy toggle with camera-proxy reuse (LRV); preview render zones that visibly invalidate; a cache/disk-usage panel; saveable dock layouts; stability before features.
- Shotcut: proxy storage choice (project vs global folder) and LRU cleanup; separate "convert to edit-friendly". Its complaints set our bar: smooth playback, live effect previews, modern UI, good docs.
- OpenChatCut / OpenTake / Palmier: an editor core independent of UI and AI; every edit a command (undoable, reviewable as a proposal); one tool surface shared by UI, scripts and (optionally) a local MCP server; hardware encode with a software fallback.

### Avoid
- Any code from LosslessCut (GPL-2), Kdenlive/Shotcut (GPL-3), Palmier/OpenTake (GPL-3), OpenChatCut (AGPL-3), quercus-otio (GPL).
- Remotion (restrictive company licence), GPL FFmpeg builds (x264/x265/`--enable-gpl`), ffmpeg.wasm "core" builds that bundle GPL encoders.
- Statically linking LGPL libs (rawler/rawloader/libheif/LibRaw) into the main binary. Use DLLs or a helper process, or OS codecs (WIC).
- Treating a GPL project as a stable base: Palmier Pro went proprietary after v0.7.6.

## Summary (10 lines)

1. Licences checked from the LICENSE files: OpenReel and OpenCut are **MIT** (reusable). **MediaBunny is MPL-2.0** (use unmodified). **LosslessCut is GPL-2.0**, so it is study-only, not reusable.
2. OpenCut classic has MIT Rust crates on wgpu 29 (compositor/effects/masks/time) that compile natively or to WASM via one `#[export]` macro: the best seed for our compositor. Its rewrite (GPUI desktop) is only a window so far.
3. OpenReel (MIT, mostly AI-written) holds the richest copyable features (LUT parser, WGSL effects, keyframes, captions, OTIO/FCPXML writers), but audit provenance and skip its GPL ffmpeg.wasm dependency.
4. MediaBunny runs in WebView2's WebCodecs: good for UI-side probing, thumbnails and scrubbing; WASM add-ons need `'wasm-unsafe-eval'`.
5. Study-only: Palmier Pro (GPL up to v0.7.6, now proprietary), its GPL fork OpenTake (exactly our stack: Rust + Tauri 2 + wgpu + FFmpeg), OpenChatCut (AGPL, Remotion), Kdenlive and Shotcut (GPL-3 on MLT).
6. Lessons: a UI/AI-free command-based editor core; proxies with per-project toggle, camera-LRV reuse, storage choice and cleanup; invalidating preview-render zones; native playback first with FFmpeg fallback, export from originals.
7. User pain to beat: Kdenlive crashes on Windows, Shotcut's dated UI, choppy playback and no effect previews, LosslessCut keyframe-snap cut inaccuracy.
8. Crates to use: num-rational, ebur128 (MIT), cosmic-text + glyphon, cpal, rubato, rustfft, whisper-rs (Unlicense, whisper.cpp MIT), ort (MIT/Apache, still RC), image, fast_image_resize, EXIF crates, rsmpeg or ffmpeg-sidecar with an LGPL FFmpeg.
9. Gaps: no live OTIO crate (write a serde model of the Apache-2.0 schema) and no waveform crate (build mipmapped peak files ourselves).
10. RAW/HEIC are LGPL territory (rawler, rawloader, libheif, LibRaw dual LGPL/CDDL): prefer Windows WIC codecs, else ship them as DLLs or a helper process, never statically linked.
